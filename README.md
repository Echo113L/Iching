# 观象 · 六爻起卦

> 万物有象 · 象由心观

一个以东方传统易经卦象为灵感的纯前端六爻起卦网页。

「观象」通过三枚虚拟铜钱进行六次起卦，由下而上生成六爻，并展示本卦、动爻与变卦；同时结合用户输入的问题与主题，提供卦辞、象辞、白话解读、典故以及主题解读，并将历史卜卦保存在浏览器本地。

这是一个 **HTML + CSS + JavaScript 单文件项目**，无需后端、数据库或构建工具，适合直接部署到 GitHub Pages。

## ✨ 功能

- **心中所问**：起卦前输入想询问的具体事项。
- **主题选择**：支持时运、财运、家宅、身体、婚恋、学业、事业、出行、官司、求职、投资等主题。
- **六爻起卦**：使用三枚虚拟铜钱，连续六次起卦，由下而上生成六爻。
- **本卦识别**：根据六爻组合自动识别六十四卦。
- **动爻判断**：根据每次三枚铜钱的结果判断老阳、少阳、少阴、老阴，并标记动爻。
- **变卦生成**：存在动爻时，根据爻变计算对应的变卦。
- **详细解读**：展示卦辞、象辞、卦象含义、白话解读、典故及主题解读。
- **主题解读**：可在同一卦象下切换不同领域，查看对应的象义。
- **卜辞存档**：历史记录保存在浏览器 `localStorage` 中，最多保存 30 条。
- **继续起卦 / 重新起卦**：结果页可保留当前问题继续起卦，也可以清空上下文开启新的卜问。
- **复制卦辞**：将本次卦象、问题、卦辞、象辞和变卦信息复制到剪贴板。
- **响应式设计**：兼容桌面端与移动端。
- **减少动画支持**：支持 `prefers-reduced-motion`，降低动画敏感用户的运动效果。

## 🎴 起卦逻辑

项目采用三枚铜钱、六次成卦的方式进行模拟起卦：

| 背面数量 | 爻 | 状态 |
|---|---|---|
| 3 | 老阳（○） | 动爻 |
| 2 | 少阳（—） | 静爻 |
| 1 | 少阴（--） | 静爻 |
| 0 | 老阴（×） | 动爻 |

每次结果会形成一爻，连续六次后由下而上构成完整六爻卦象。

## 🎨 设计方向

项目采用偏东方神秘学的视觉语言，而不是传统“古风工具站”风格，主要使用：

- 墨黑 / 黛青背景
- 宣纸色内容区域
- 古铜金强调色
- 宋体 / 中文衬线字体作为主要内容字体
- 低饱和、低对比的装饰纹理
- 铜钱翻转与卦象逐爻出现动画
- 本卦 → 动爻 → 变卦的结果流

核心目标是让“起卦”不仅是功能操作，也是一个完整的数字仪式体验。

## 🚀 本地运行

由于项目是纯静态网页，直接双击 `index.html` 即可运行。

也可以使用任意静态服务器运行，例如 VS Code 的 Live Server，或者：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 🌐 部署到 GitHub Pages

### 方式一：直接使用 GitHub 网页上传

1. 在 GitHub 创建一个新的 Repository。
2. 上传 `index.html` 和 `README.md`。
3. 进入 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 `main` 分支与 `/root` 目录。
6. 保存后等待 GitHub Pages 完成部署。

### 方式二：使用 Git

```bash
git init
git add index.html README.md
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

之后在仓库的：

```text
Settings → Pages → Deploy from a branch
```

选择 `main / root` 即可。

## 💾 数据与隐私

「卜辞存档」使用浏览器本地 `localStorage` 保存，不需要服务器，也不会因为部署到 GitHub Pages 而自动上传到远端数据库。

因此：

- 更换浏览器后不会自动同步记录。
- 清除浏览器站点数据可能会删除历史记录。
- GitHub 仓库本身不会保存用户在页面中输入的问题或卦辞记录。

## 📜 内容说明

项目中的六十四卦、卦辞、象辞、爻辞以及部分白话、典故与主题内容均作为网页内置内容使用。
